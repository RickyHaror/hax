# Terminal first mockups, version 1

Founder approved design mockups for the terminal first direction (docs/TERMINAL-PLAN.md), copied
2026-11-08 from the founder's design canvas. Reference only: the game never loads these files.

- Screens at 1366x768 (`*Desk`, `Main` is start up) and 390x844 (`*Phone`): start up, mission card,
  exploring files, network map with the Help me ladder, password lesson, trick email, unlocked,
  agent profile, season map, pretend computers.
- Design system: `DSFoundations` (color and type tokens, spacing), `DSComponents` (terminal window,
  command chip, command bar, sidekick bubble, mission card, rank badge, clue toast), `DSMotion`.
- Each file is self contained HTML with its styles in the `<style>` block; open it in a browser to view.
  `canvas.json` lists the screens and their titles.
- Fonts: JetBrains Mono and Inter, to be self hosted. No external URLs.
